# 桌宠接口面（pet interface）

桌宠是**旁路产品**：独立版本线（`@linxiraos/pet`，不跟 Zeta 1.x 走）、独立安装、独立发布。
Zeta 侧只承诺本文件里的接口，不内嵌、不 import 桌宠的任何代码。接口面变动按破坏性变更处理。

## 1. 归属：默认工作区

- 生效配置的**唯一权威位置**是默认工作区的 pet 目录：`~/.zeta/workspace/pet/`，即
  `pet.json` + 素材目录（相对 `pet.json` 解析）。
- 全局目录 `~/.zeta/pet/` 只作为**缺省回退**：默认工作区没有配置时读它，有则忽略。
- 其他工作区不持有 pet 配置；工作区之间不合并、不覆盖。桌宠启动时按
  `$ZETA_PET_DIR` → 默认工作区 → 全局 的顺序选目录。

## 2. 状态：桌宠只读，agent 只写

- 路径：`<pet 目录>/state.json`。
- 形状：`{ "state": string, "text"?: string, "since": number }`。
  - `state` ∈ `idle | thinking | working | done | error | dragging | clicked`；
    未知值必须降级为 `idle`，不得退出。
  - `text` 是单行气泡文案，超长自行截断；缺省不显示。
  - `since` 是毫秒时间戳，用来忽略乱序写入。
- 写入方：Zeta 运行时（`state` 表示本次会话的 agent 状态）。读取方：桌宠，轮询间隔
  ≤ 500 ms；文件缺失/半写/解析失败时保持上一个状态，不报错、不退出。

## 3. 移动：默认自主，工作区可按需干预

- 默认：桌宠自己决定在哪里待着（怠速漫游、贴边、跟随活动窗口），Zeta 不介入。
- 可选通道：`<pet 目录>/commands/`（一次性文件，桌宠处理后删除）。
  - `move.json`：`{ "x": number, "y": number, "monitor"?: string, "durationMs"?: number }`
    —— 仅当工作区显式要求（例如把宠物叫到某个屏）时下发。
  - `say.json`：`{ "text": string, "ttlMs"?: number }` —— 气泡，不改变动作状态。
- **不提供**让模型自由读写屏幕坐标的 API；坐标只能由用户动作或工作区显式指令产生。

## 4. 不变量

- 桌宠崩溃不影响 Zeta；Zeta 崩溃时桌宠保持最后状态并在文件恢复后继续。
- 桌宠不得读写 `~/.zeta` 下除自身目录与状态文件以外的任何内容。
- 状态文件与命令目录都是**只增不改**的契约；加字段可以，改语义要新版本。

## 5. 素材与授权

- 素材生产：文生图角色表 → 图生视频（绿幕）→ 抠像/抽帧 → 图集 + 清单。
- 参考实现（**只取方法，不入库素材**）：`dsh-pet`（代码 MIT，素材「可开源使用、禁商用」）、
  `simiao-dsh-pet`（脚本与文档 MIT，`pet-pack/` 与 `assets/` 生成的素材**不在 MIT 内**，
  禁商用且必须署名）、`DeepSeek-Pet`（代码 MIT，角色素材归属其作者）。
- 生成平台（即梦/可灵等）的条款、以及生成物的再分发规则，发布前逐项核对；商用前必须另行确认。
