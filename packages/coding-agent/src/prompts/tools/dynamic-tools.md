Dynamic tools are user-toggled capabilities (`/tool <name> on|off`). The user may turn one on or off at runtime; each toggle delivers a one-line system notice naming the tool, its capability, and the current mode. While a capability is off, do not rely on or reference it. The `time` tool stays callable either way so you can switch its time injection back on yourself with `action: "on"` (or `"off"` / `"status"`); an enable notice means the capability is active from that point on.
