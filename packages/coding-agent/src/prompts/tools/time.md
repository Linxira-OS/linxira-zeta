Get the current exact time: local wall clock (YYYY-MM-DD HH:mm:ss, weekday, zone name and UTC offset), UTC in the same format, and epoch milliseconds. Optional `timezone` takes an IANA name (e.g. "Asia/Shanghai"); omitted uses this machine's local zone; an invalid name errors with the count of supported zones.
While this tool is enabled, user messages carry a trailing `[发送时间: …]` line — that marks when the message was SENT, not now. Long sessions drift across days: before dating anything ("today", logs, commits, schedule entries) or reasoning about "now", call `time` first.
