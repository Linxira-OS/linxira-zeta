Manage persistent canvas scenes in this repository. Files live under `.canvas/` at the repository root; organize them in subdirectories as needed: `.canvas/<slug>.excalidraw` (Excalidraw JSON) or `.canvas/<slug>.canvas` (Obsidian Canvas JSON). Ops: `list`; `create` with `title` and optional `kind` (`excalidraw` default, or `obsidian`); `outline` with `path` (relative to `.canvas/`). Use canvases for editable diagrams, visual notes, and whiteboards the user opens in Obsidian or Excalidraw; `read <file>:img` renders a terminal preview. Created canvases start empty; fill elements with `write`/`edit`.
