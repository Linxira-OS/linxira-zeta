Manage canvas scenes under `.canvas/` (Obsidian `.canvas`, Excalidraw `.excalidraw`). Ops: `list`; `create` (title, kind) writes an empty scene; `write` (path, nodes, edges) replaces a scene; `outline` (path) summarizes one. Nodes are `{id?, text, x, y, width?, height?}`; edges are `{from, to, label?}`. Files are JSON for Obsidian/Excalidraw; `read <file>:img` renders a terminal preview.
