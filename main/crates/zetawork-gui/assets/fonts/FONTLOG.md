# FONTLOG

## Maple Mono CN Regular

- Upstream project: [Maple Mono](https://github.com/subframe7536/maple-font)
- Upstream version: 7.9
- Source package: `@automann/maple-mono-cn` 7.9 (non-Nerd-Font CN build)
- Bundled file: `MapleMono-CN-Regular.ttf`

The bundled file is the official `MapleMono-CN-Regular.ttf` from that package,
included unmodified. It covers Latin, the Braille Patterns block (U+2800–U+28FF),
and CJK with a 1:2 advance ratio; the GUI only embeds this one weight.
