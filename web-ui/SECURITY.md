# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in Zeta Web, please do NOT open a public issue.

Instead, please report it privately by opening a [GitHub Private Vulnerability Report](https://github.com/Linxira-OS/linxira-zeta/security/advisories/new) or contacting the maintainers directly.

Please include:
- A description of the issue and potential impact.
- Steps to reproduce or proof-of-concept code.

We will acknowledge receipt of your report within 48 hours and provide status updates as we investigate and address the issue.
