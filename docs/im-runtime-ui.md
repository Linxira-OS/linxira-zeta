# IM 运行时（Work Studio / TUI）

> 状态：Work Studio 实例保存已有本地浏览器验证；TUI 分层设置已有隔离网关、组件及 Windows ConPTY 交互验证。真实扫码与外部平台全链路仍未验。
> 后端契约见 [ADR 0029](../document/adr/0029-im-switch-gateway.md) / [ADR 0030](../document/adr/0030-im-secret-storage.md)；TUI 复用权威见 [ADR 0067](../document/adr/0067-tui-runtime-settings.md)（Proposed）。
> 命令统一推荐 ASCII `!`；旧 `@` 别名仍兼容但不作为推荐入口。本页不记录临时分支或不存在的行为。

## 打开

- **Work Studio**：设置 → **IM 运行时**（也可用命令面板搜索“IM 运行时”）。
- **桌面应用**：同一个 Work Studio 设置页，没有第二套界面。
- **TUI**：`/settings` → **运行时 / Runtime** → **身份与设备** 或 **IM 运行时**。
  `/2fa` 和 `/channels` 直接打开同一子页。鼠标点击条目、返回和提交按钮；键盘
  使用已配置的选择、确认、取消键（默认方向键、Enter、Escape），逐层返回。
- TUI 页面需要同版本、已注册且可达的本机 `zetacode serve`。未启动或版本不匹配
  会显示原因与重试入口；先启动或重启 serve，再重试。
- `/2fa status` 保留脱敏状态输出；`/channels status`、
  `/channels enable-instance <id>`、`/channels disable-instance <id>` 保留管理命令。

## TUI 身份与设备

身份页可查看绑定状态，显示验证器临时字符二维码与完整手动密钥、确认动态码、
验证动态码或恢复码、修改远程写入策略、重新生成恢复码、停用验证器，以及显示
设备配对码和撤销指定设备。重新绑定、停用和撤销设备会要求再次确认所选操作。

二维码、手动密钥、恢复码和平台凭据仅在临时设置界面展示或输入，不写入会话、
模型上下文或普通日志。返回、关闭或过期会清除页面持有的临时内容；过期后需要
重新获取。终端过窄或过矮时使用完整换行文本，可滚动查看，不截断二维码让人误扫。
配对仍受既有本机／二次验证规则约束；外部设备推送确认尚未实现。

## 实例

同一平台可以有多个实例（例如两个飞书机器人、一个工作号一个角色号）。每个
实例有：

- 不可变的实例 ID（运行时命名空间，创建后不能改名）、显示名、备注；
- 允许的聊天（`peers`，必填，默认拒绝）与可选用户；
- Agent Profile、启用开关、默认目标；
- 平台凭据：留空表示保留已保存值，填入新值则替换。已保存密钥不会回传明文；
  Work Studio 另有显式清除选项。TUI 在实例的“平台登录 / 凭据”临时子页输入，
  选择“验证并保存”后才提交；返回会丢弃该页未保存的输入。
- 每实例独立的微信登录二维码、重新连接、解绑。

平台校验会先在平台侧验证凭据（不写盘），成功显示机器人身份，失败显示脱敏
错误。启用一个实例只影响该实例；同一平台的另一个实例不受影响。

## 绑定

一条绑定把一个聊天的流量交给一个 Agent Profile 和一个目标：

- 目标可以是工作区别名、Team PM 或 Engineer（由后端解析，目标不可用时不能保存）；
- 会话通过下拉框按**名称**选择，不要求输入内部 ID。可选范围来自后端
  `GET /api/im/conversations`：已有 Bot 会话和现有 Studio/TUI/main 转录（名称、
  工作区、入口数量、可用原因）。选中现有 Studio/TUI 转录时，后端
  `POST /api/im/conversations/attach` 只登记同一文件，不复制、不改写历史；
  真正启动/收到 IM 消息后才会写入 IM origin；
- **显式共享**：多个入口（不同实例、不同聊天，或同一聊天的不同 thread/用户）
  可以选择同一个会话。它们必须使用同一目标、同一 Agent Profile 和同一模型
  覆盖；任何一项冲突都会拒绝保存，不会静默改绑或分叉。只有显式选择同一会话
  才共享历史；Profile/目标相同不会自动合并；
- 共享后，所有入口读写同一历史、记忆与目标；会话目标/Profile/模型由会话锁定，
  单个入口不能改走。解除一条绑定只影响该入口，不关闭、不重命名、不切换其他
  入口或会话；
- TUI 必须显式选择已有会话；尚无合适会话时，先在 Studio/TUI 创建并发送一条
  消息，再回到绑定列表刷新选择。Work Studio 的新会话选项在首条消息后创建；
  TUI 绑定页不会隐式创建会话。
- 角色：
  - `answer`：自动回复该聊天（每个 platform + chatId 只允许一个）；
  - `mention`：只在本实例的机器人被 @ 时回复，**不自动回复**，同一聊天可有多条；
  - `observe`：只记录，从不发送。
- 显示目标、Profile、会话名称、模型，以及 `needsReview` / 目标不可用的原因；
  处于这些状态的绑定不会被当成可用目标。原始会话/转录 ID 不在普通表格显示，
  只保留在后端与诊断接口。

共享是明确的信任扩张：同一会话里的所有入口都能读到其它入口的消息历史。
要隔离私密对话时，请选择不同会话。运行中的会话会将新到的 IM 消息排入后续轮次。
模型收到正文与发件人，回复按投递时的实例、聊天和 thread 归属发送。各平台对
thread 和消息引用的实际支持由适配器决定。

## Agent Profile

Profile 决定机器人如何回复：

- persona（inline 文本 / 文件 / 工作区）与模型；
- 位置：工作区、Team PM 或 Engineer；
- 工具白名单（每行一个）：builtin、extensions、MCP servers、custom tools、
  skills、commands，另有工具预设与审批模式。**空列表表示没有**，不会继承环境
  里的工具；custom tools 默认空。`capabilities` 已从 schema 删除，本页不提供
  权限开关，也不会标示未建模的权限；
- 记忆后端、命名空间与是否携带工作区上下文；
- 运行时身份（含 bindingId）由后端计算，页面只展示、不自拼。

## Bot 状态

选择实例与聊天后，可查看后端解析出的绑定、会话、模型、answer/mention/observe、
语音能力与命令示例，并从该实例发送一条测试消息。语音当前不支持时会显示原因。

## 错误与限制

- 加载中、空列表、网关错误分别显示；没有后端成功的操作不会显示成功。
- 缺平台账号时，实例显示未配置/平台错误；真实机器人回复需要真实平台账号，
  本页不会伪造在线状态。
- 每个绑定的完整运行时命令预览仍有限；页面只展示后端能给出的字段。
- TUI 的 Agent Profile ID 是配置身份；它不等于 Team worker 的角色、agent 定义或
  生命周期。目标、Profile 和模型锁仍由现有会话与网关校验，不能从单个入口改走。
- TUI 验证使用隔离凭据与 TOTP store；Windows addon 为 1.5.1、源码为 1.5.2，
  不构成当前源码匹配 native、实机扫码或真实外部平台验收。
