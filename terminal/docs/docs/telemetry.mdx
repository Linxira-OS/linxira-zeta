## Zeta Terminal collects and exports no telemetry

This fork does not send Wave telemetry, Wave diagnostic pings, or Wave AI
telemetry. There is no opt-in switch that re-enables uploads: the server's
telemetry loops return immediately, `SendTelemetryCommand` and
`WaveAIEnableTelemetryCommand` are no-ops, and `IsTelemetryEnabled()` always
returns `false`.

The `telemetry:enabled` setting and the inherited Wave telemetry document are
kept only so the vendored tree merges cleanly with upstream. They do not cause
collection, local event writes, or network requests in Zeta Terminal.

`wsh debug send-telemetry` is also a no-op (the command remains for upstream compatibility). No ClientId, version, OS, command,
file, or usage record leaves the machine.
